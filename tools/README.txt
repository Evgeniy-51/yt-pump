Place these files in this folder (same names):

- yt-dlp.exe
- ffmpeg.exe      (LGPL shared build, mux only)
- ffprobe.exe
- deno.exe        (JS runtime required by current YouTube extractor)

Do not put them on PATH. YtPump looks only here, next to the executable
(or next to the published YtPump.exe in the portable zip).

Download sources (verify checksums yourself):
- yt-dlp: https://github.com/yt-dlp/yt-dlp/releases
- ffmpeg: https://github.com/BtbN/FFmpeg-Builds/releases (choose an LGPL build)
- deno:   https://github.com/denoland/deno/releases
